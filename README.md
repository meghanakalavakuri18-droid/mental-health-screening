
# Mental Health Screening & Crisis Detection

## About the Project
A Python Flask-based educational application
that helps users reflect on their mental wellbeing
and access crisis support resources.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Features
- User information form
- Mental wellbeing questionnaire
- Screening score calculation
- Safety check
- Crisis support information
- Screening results page
- SQLite database

## Installation

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open in browser:

   http://127.0.0.1:5000

## Disclaimer
This is an educational prototype.
It does not provide medical diagnosis or
professional mental health treatment.
